## Apache Airflow
Apache Airflow is an open-source platform used to programmatically author, schedule, and monitor workflows. It allows you to define complex workflows as code and manage their execution. It is used for data pipelines, where tasks such as data extraction, transformation, and loading (ETL) are orchestrated across multiple systems

Tasks represents the individual unit of work in a DAG

Dependencies
Tasks in a DAG have dependencies, meaning one task might need to finish before another task can start.
